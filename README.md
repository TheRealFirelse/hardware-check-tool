# hardware-check-tool

A simple system monitoring program that displays real-time CPU and RAM usage (%).

## Description
This program shows current CPU and RAM usage every 2 seconds.

Also this program shows you warnings when your CPU or RAM usage is high.
And if your CPU is exceeds 89%, it recommends stopping the most CPU-intensive process and can terminate it with user confirmation.

It helps you monitor system load and take action before performance drops or thermal throttling occurs.
